Discord embed card:

```text
OPENED · #PR_NUMBER TITLE          ← linked to PR_URL
SHORT DESCRIPTION                  ← opened PRs and description edits only
Reviewers: REQUESTED REVIEWER(S)   ← opened PRs when present
PR by AUTHOR
```

`OPENED`, `CHANGES PUSHED`, `EDITED`, `MERGED`, and `CLOSED` each use a distinct card color.
Edited cards state whether the title, description, or target branch changed.
